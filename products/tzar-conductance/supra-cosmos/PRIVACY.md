# Приватность Supra XR COSMOS PORTAL

Основной анализ выполняется локально в браузере. Выбранные изображения не отправляются на сервер, не сохраняются Service Worker и не встраиваются в JSON-паспорт.

Паспорт содержит только явно введённый объект, размеры и количество выделенных узлов, WCS при наличии, производные метрики, гипотезы и `Q=null`. Файл создаётся только по команде пользователя.

Приложение хранит в `localStorage` только выбранный язык. Доступ к датчикам ориентации в XR-лаборатории запрашивается отдельно и используется только для текущего отображения сцены.

Публикация размещается как статический сайт GitHub Pages. Обычные сетевые журналы хостинга могут применяться самим GitHub согласно его политике.
