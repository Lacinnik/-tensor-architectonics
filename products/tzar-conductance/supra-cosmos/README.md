# Supra XR COSMOS PORTAL

`0.4.0-candidate` — публичный инженерный кандидат локального пространственного проводника TeZar.

Портал принимает две пользовательские проекции, выделяет световые узлы, оценивает фон и сенсорный остаток, сравнивает топологию парных расстояний со случайным полем и создаёт переносимый JSON-паспорт Новой Точки.

## Граница метода

- вычислительный оператор безвременной: календарная ось не входит в `Γ_g`; EXIF может использоваться только как provenance;
- объект `O` задаёт исследователь, интерфейс не распознаёт галактику или физическую причину автоматически;
- `P_invariant excess` — относительный структурный кандидат, не вероятность и не измерение эфира;
- `Q=null` сохраняется до наблюдаемого внешнего отклика;
- изображения декодируются в браузере, не загружаются и не входят в экспорт;
- WCS вводится вручную и остаётся `null`, если не заполнены все четыре поля.

## Локальный запуск

Подойдёт любой статический HTTP-сервер. Основной модуль не требует сборки и внешних библиотек. XR-лаборатория использует только WebGL/Canvas API браузера; WebXR и датчики включаются по явному действию пользователя.

## Контракт

`O → S → I → R_g @ C`, сингулярная точка `O ⊕ I`, ранжирование `Γ_g = α × IЯ × C_m × R_g × 100`.

Статус: `candidate`, не `verified` и не `canonical`.
